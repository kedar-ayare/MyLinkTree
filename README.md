# My Link Tree

A simple, responsive personal link page that brings all my important links and social profiles together in one place.

## 🔗 Links

The page provides quick access to:

- 💼 LinkedIn
- 💻 GitHub
- 📸 Instagram
- 🌐 Personal Website
- 📧 Other social and professional profiles

## ✨ Features

- Clean and minimal UI
- Responsive design for desktop and mobile
- Custom background
- Social media and profile links
- Lightweight — no frameworks or backend required

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 📱 Responsive Design

The page is designed to work across different screen sizes, including:

- Desktop
- Tablet
- Mobile
